## Java Zero Copy Packet Utils

### Overview

This project provides a Java-based utility for real-time zero-copy network packet assembly and disassembly, aiming for efficient network communication.

### Files
- `src/main/java/com/packetutils/PacketAssembler.java`
- `src/main/java/com/packetutils/PacketDisassembler.java`
- `pom.xml`
- `build.sh`
- `test.sh`

### Compilation and Testing
- `make test`
- `bash test.sh`
